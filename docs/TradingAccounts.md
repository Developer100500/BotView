# Торговые счета

Кнопка **Торговые счета** в MainWindow открывает управление профилями Binance и Bybit.
Поддерживаются спотовые счета с HMAC API key/secret, Testnet и основная сеть.
Bybit Demo и подключение счетов QUIK в эту версию не входят.

1. Нажмите **Добавить счет**, задайте название, биржу и среду. По умолчанию выбран Testnet.
2. Введите API key и API secret в маскированные поля и нажмите **Сохранить**.
3. **Проверить подключение** читает данные счета и доступные сведения о правах API.
   Ордеров и запросов на вывод приложение не отправляет.
4. **Выбрать для биржи** сохраняет активный профиль для будущего торгового сервиса.
   Для каждой биржи выбирается один профиль. Подключение Buy/Sell остается заглушкой.

Ключи хранятся **только в ОЗУ до закрытия приложения**. Закрытие окна счетов их
не удаляет; они остаются доступны при повторном открытии окна в том же процессе.
После перезапуска у профиля появится статус **Нужны ключи**. Введите оба значения
заново и сохраните профиль. Название, биржа, среда и выбор счета сохраняются отдельно
в `%LOCALAPPDATA%/BotView/trading-accounts.json`, без ключей и результатов проверки.
Windows Credential Manager и DPAPI не используются.

Сохраненные ключи не подставляются в форму. Для замены нажмите **Заменить ключи**, введите оба новых значения
и сохраните; для переименования достаточно изменить название. Биржа и среда
существующего профиля неизменяемы: создайте другой профиль для другого подключения.
**Удалить** удаляет профиль и его ключи из памяти, но не отзывает API-ключ на бирже.

Доступ к чтению счета и торговые разрешения проверяются отдельно. В Binance Spot
Testnet нет `/sapi`, поэтому подключение может быть подтверждено при неизвестных правах.
Если сведения о правах недоступны, приложение не считает торговлю разрешенной.
Для торговли достаточно чтения и спотовой торговли без права вывода.

Проверка выполняется в фоне отдельным авторизованным CCXT-клиентом с общим тайм-аутом
15 секунд. Смена выбранного профиля, кнопка отмены и закрытие окна отменяют проверку.
Основная сеть не используется как запасной адрес для Testnet. Клиенты публичного
стакана, графика и QUIK не получают ключей и продолжают работать независимо.
Результаты и ошибки не содержат исходные ответы API, подписанные URL или секреты.

Автоматические проверки используют вымышленные ключи и подставные ответы:

```powershell
dotnet build BotView.sln --no-restore -m:1 -p:UseSharedCompilation=false
dotnet BotView.Tests/bin/Debug/net10.0-windows7.0/BotView.Tests.dll -class BotView.Tests.TradingAccountTests
```

Для ручной проверки реального Testnet-подключения введите соответствующие ключи
непосредственно в окно приложения и нажмите **Проверить подключение**.
