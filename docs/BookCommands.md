# Команды стакана и настройки

Кнопка **Горячие клавиши** в главном окне или стакане открывает общие назначения.
**Настройки (F4)** открывает параметры конкретного подключения и инструмента.
Назначения общие для приложения; параметры инструмента и наборы объёмов независимы
для каждого полного `InstrumentKey` и подключения. Настройки сохраняются в
`%LOCALAPPDATA%/BotView/book-commands.json`, формат версии 1.

## Исполнение

Все новые команды, кроме открытия настроек и выбора рабочего объёма/его единиц,
вызывают `StubCommandInvocationHandler`. Обработчик не получает торговый сервис,
не размещает, не изменяет и не отменяет заявки. Он не создаёт уровни, не меняет
прокрутку, масштаб, маркет-дату или выбранный фьючерс. Строка под рабочими объёмами
показывает последний принятый вызов; подсказка содержит полный контекст.

Сохранённые SL/TP и трейлинг — только параметры. Они не защищают позицию,
не наблюдают за ценой и не запускают автоматические операции. Выбор «Сервер»
не подтверждает поддержку исполнения брокером.

Существующие Buy/Sell, торговля мышью и отмена в окне Orders для криптовалют
сохраняют свой прежний путь исполнения. Новые клавиши к этому пути не подключены.
Для QUIK существующие торговые кнопки и отмена отключены.

## Назначения

| Клавиша | Команда | Вызов |
| --- | --- | --- |
| F4 | Настройки инструмента | Нажатие, настоящее окно настроек |
| 1–5 | Рабочий объём | Нажатие, закреплённые клавиши верхнего ряда |
| M | Единицы ввода объёма | Нажатие, выбор количества или денежной суммы |
| A / S | Лимитная покупка / продажа | Нажатие, stub |
| T / Y | Рыночная покупка / продажа | Нажатие, stub |
| D / R | Закрытие / переворот | Нажатие, stub, только фьючерсы |
| F / B | Отмена лимитных / стоп-заявок | Нажатие, stub |
| Q | Прерывание команды | Stub и сброс незавершённого локального режима |
| C | SL/TP | Удержание и клик по цене |
| N | Трейлинг | Нажатие, stub |
| V / Z | Стоп-заявка / заявка на закрытие | Нажатие и следующий клик |
| LeftAlt / X | Закрытие с удержанием / первый объём | Удержание и клик |
| L / K | Уровень / сигнальный уровень | Удержание и клик |
| O | Удаление уровней | Нажатие, stub |
| Oem3 | Ускоренная прокрутка | Удержание и колесо, stub |
| H | Изменение шага колесом | Удержание и колесо, stub |
| + / − | Увеличить / уменьшить шаг | Нажатие, stub |
| E | Единицы объёмов стакана | Нажатие, stub |
| G | Линейка | Нажатие и два клика по ценам |
| P | Маркет-дата подключения | Нажатие, stub |
| Не назначены | Маркет-дата всех подключений; разворот стакана/графика; следующий/предыдущий фьючерс | Назначаемые stubs |

R изначально выключена. Команды без назначения выключены. Числа NumPad
не выбирают рабочий объём. При конфликте новое назначение отклоняется.
`Esc` отменяет захват назначения или текущий режим. Повтор V/Z отменяет режим;
отпускание удерживаемой клавиши завершает удерживаемый режим.

Ввод работает только в активном BotView над областью стакана, вне редакторов,
меню и диалогов. При уходе курсора со стакана, потере фокуса или закрытии окна
незавершённый режим сбрасывается. Клики и колесо активного режима поглощаются,
включая двойные клики и попадания вне отрисованных строк: они не попадают в
существующую торговлю мышью.

Начальные пять объёмов пустые. Количество и денежные суммы хранятся отдельно;
они не меняют поля существующей торговой формы. Неизвестные счёт, цена и объём
передаются в stub как неизвестные, без подстановки нулей.

## Проверки

```powershell
dotnet build BotView.sln --no-restore -m:1 -p:UseSharedCompilation=false
dotnet BotView.Tests/bin/Debug/net10.0-windows7.0/BotView.Tests.dll -class BotView.Tests.BookCommandTests -class BotView.Tests.QuikReadOnlyTests
```

Тесты не отправляют торговые запросы. Для экспорта предпросмотра окна настроек
перед запуском `BookCommandTests` задайте `BOTVIEW_COMMAND_PREVIEW` абсолютным
путём PNG. Тесты содержат проверку полного реестра, настроек, жестов, изоляции
инструментов, гонок снимков и событий и запрета мутаций QUIK.
