# Стакан

ПКМ по торговой паре в избранном, результатах поиска, поиске сравнения или списках
роста/падения → **Стакан**. Окно закрепляется за парой и биржей, выбранной при открытии.
Повторное открытие активирует существующее окно. Другие пары и биржи открываются отдельно.

- Колесо мыши прокручивает цены и отключает слежение за рынком.
- **К рынку** возвращает центрирование по середине лучших bid/ask.
- **×1 / ×5 / ×10** задает множитель минимального шага цены биржи.
- Клик по строке переносит цену в поле заявки.
- **Buy / Sell** проверяют положительные цену и объем и показывают торговую заглушку.
  Ордер не отправляется.

Красные строки относятся к продавцам, зеленые — к покупателям. Спред имеет нейтральный
фон. Нулевой объем означает пустой уровень внутри известной глубины; **—** означает,
что уровень находится вне загруженной глубины и объем неизвестен. При укрупнении шага
объемы и стоимость предложений суммируются, цены bid округляются вниз, ask — вверх.

Каждое окно использует отдельный публичный CCXT.Pro-клиент и до 100 уровней на сторону.
Обычные CCXT-клиенты графика не участвуют в подписке стакана. Фоновая задача загружает
спотовые метаданные, получает `WatchOrderBook` и копирует кеш библиотеки в независимые
снимки. UI выбирает последний снимок по таймеру 50 мс; рисуются только видимые строки.
При разрыве последний снимок остается с предупреждением, повторные подключения
выполняются с задержками 1, 2, 4, 8, 16, 30 секунд. Закрытие окна отменяет ожидание
и закрывает его собственный клиент.

Проверки (из корня репозитория):

```powershell
dotnet build BotView.sln --no-restore -m:1 -p:UseSharedCompilation=false
dotnet BotView.Tests/bin/Debug/net10.0-windows7.0/BotView.Tests.dll -class BotView.Tests.OrderBookTests -class BotView.Tests.CoinInfoTests
```

Для отдельной проверки публичных Binance/Bybit одновременно с обычной загрузкой свечей:

```powershell
$env:BOTVIEW_LIVE_ORDERBOOK = '1'
dotnet BotView.Tests/bin/Debug/net10.0-windows7.0/BotView.Tests.dll -method BotView.Tests.OrderBookTests.LiveProFeedWorksAlongsideExistingRestCandles
```

`BOTVIEW_ORDERBOOK_PREVIEW` задает путь PNG для проверки отрисовки окна на тестовых данных.
